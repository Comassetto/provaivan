1. FIRST e FOLLOW — colinha §3

1.1 ★ AVA Q10
Como acertar: elimine. A e tem $ no FIRST. A regra de A começa com i, então FIRST(A) = {i} e a d sai. C começa com n ou i, então FIRST(C) = {n, i} e a b sai. Entre a e c: o B só aparece antes de "]" e não fica no fim de nenhuma regra do inicial, então o FOLLOW(B) não tem $ → a.
Dada a gramática a seguir, assinale a opção que apresenta corretamente os conjuntos FIRST e FOLLOW:
A → i [ B ] = C · B → n | n B · C → n | i | i C
  • a. FIRST(A) = {i} · FIRST(B) = {n} · FIRST(C) = {n, i} — FOLLOW(A) = {$} · FOLLOW(B) = {]} · FOLLOW(C) = {$}
  • b. FIRST(A) = {i} · FIRST(B) = {n} · FIRST(C) = {n} — FOLLOW(A) = {$} · FOLLOW(B) = {], $} · FOLLOW(C) = {$}
  • c. FIRST(A) = {i} · FIRST(B) = {n} · FIRST(C) = {n, i} — FOLLOW(A) = {$} · FOLLOW(B) = {], $} · FOLLOW(C) = {$}
  • d. FIRST(A) = {i, [} · FIRST(B) = {n} · FIRST(C) = {n} — FOLLOW(A) = {$} · FOLLOW(B) = {], $} · FOLLOW(C) = {$}
  • e. FIRST(A) = {$} · FIRST(B) = {]} · FIRST(C) = {$} — FOLLOW(A) = {i} · FOLLOW(B) = {n} · FOLLOW(C) = {n, i}

4. Teoria: descendente e ascendente — colinha §1 e §2

4.1 ★ AVA Q6
Como acertar: a a e a e são frases do slide com um "não" enfiado. A b e a d descrevem a descendente (lado trocado). Sobra a c.
Assinale as afirmações corretas em relação à Análise Sintática Ascendente:
  • a. Nessa abordagem, não ocorre a construção de uma árvore de derivação
  • b. De uma maneira simplificada, podemos dizer que esse analisador inicia com o símbolo inicial da gramática e vai fazendo sucessivas substituições até conseguir gerar a sentença que está sendo reconhecida
  • c. Também chamada de shift-reduce devido às sucessivas operações de substituir e reduzir que são realizadas durante o reconhecimento
  • d. Também chamada de top-down pois a árvore de derivação é montada de cima para baixo
  • e. Os analisadores LR Canônicos são os mais poderosos, mas não podem ser implementados por meio de um autômato com pilha
4.2 Slide Aula07 sl.3
Na gramática C → atr · C → if (E) C else C · C → if (E) C · E → exp, ao obter o token if, qual regra de produção escolher?
Resposta: só com o if não dá para saber, porque as duas regras começam igual. Se escolher a errada, é preciso voltar (ASD com retrocesso). A solução é fatorar para retardar a decisão: C → if (E) C X · X → else C | ε.
4.3 Slide Aula07 sl.5
A gramática S → aAb | b · A → aA | B · B → bB | ε tem ambiguidade? Tem recursão à esquerda? Já pode ser implementada com ASD recursiva com retrocesso?
Resposta: não tem ambiguidade · não tem recursão à esquerda · sim, já pode.

8. Lex / Flex — colinha §9

8.1 ★ AVA Q5
Como acertar: %{ %} guarda código C copiado (constantes), e as ações ficam entre os %% (a b é falsa). {numero} pede uma definição chamada numero (a c é falsa). O Lex gera um programa em C, não lê o texto (a a é falsa).
Assinale as afirmações verdadeiras em relação ao gerador de analisador léxico LEX ou FLEX:
  • a. O programa Gnu Lex recebe como entrada um arquivo .lex e um arquivo .txt, a seguir ele lê cada linha do arquivo texto e extrai os tokens de acordo com a interpretação do arquivo lex
  • b. No arquivo fonte lex, a região iniciada por %{ e finalizada por %} serve para descrever a ação a ser tomada quando o padrão for reconhecido
  • c. A seguinte regra de tradução é válida desde que exista uma definição regular para a expressão NUM: {numero} {return (NUM);}
  • d. No arquivo fonte lex, a região iniciada por %{ e finalizada por %} possibilita declarar constantes que serão copiadas sem modificações ao código C
  • e. No arquivo fonte lex é possível especificar definições regulares reutilizando outras definições especificadas anteriormente, como por exemplo n_real {digito}.{digito}+

9.2 Slide Aula11 sl.3
Considerando C = A + B;, quais os possíveis problemas semânticos?
Resposta: A, B ou C não foram declarados (consulta à tabela de símbolos) · os tipos de A e B não permitem a soma · o tipo do resultado não pode ser guardado em C.
