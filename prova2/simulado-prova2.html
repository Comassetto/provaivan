1. FIRST e FOLLOW — colinha §3

S1.1 escolha uma opção pegadinha: FIRST com 2 símbolos e $ no lugar errado
Dada a gramática P → p ( Q ) R · Q → q | q Q · R → r | p | p R, assinale a opção que apresenta corretamente os conjuntos FIRST e FOLLOW:
  • a. FIRST(P) = {p, (} · FIRST(Q) = {q} · FIRST(R) = {r, p} — FOLLOW(P) = {$} · FOLLOW(Q) = {)} · FOLLOW(R) = {$}
  • b. FIRST(P) = {p} · FIRST(Q) = {q} · FIRST(R) = {r, p} — FOLLOW(P) = {$} · FOLLOW(Q) = {), $} · FOLLOW(R) = {$}
  • c. FIRST(P) = {p} · FIRST(Q) = {q} · FIRST(R) = {r, p} — FOLLOW(P) = {$} · FOLLOW(Q) = {)} · FOLLOW(R) = {$}
  • d. FIRST(P) = {p} · FIRST(Q) = {q} · FIRST(R) = {r} — FOLLOW(P) = {$} · FOLLOW(Q) = {)} · FOLLOW(R) = {$}
  • e. FIRST(P) = {$} · FIRST(Q) = {)} · FIRST(R) = {$} — FOLLOW(P) = {p} · FOLLOW(Q) = {q} · FOLLOW(R) = {r, p}
Como acertar: o P só começa com p (o parêntese vem depois), logo a "a" sai. Q só aparece antes do ")", então FOLLOW(Q) = {)}, e a "b" sai. R tem três regras: r, p e pR, então FIRST(R) = {r, p}, e a "d" sai. A "e" tem $ no FIRST, sai.
S1.2 escolha uma opção pegadinha: ε no FOLLOW e FOLLOW que some
Dada a gramática S → a B D · B → b | ε · D → d, assinale a opção correta:
  • a. FIRST(B) = {b} · FOLLOW(B) = {d}
  • b. FIRST(B) = {b, ε} · FOLLOW(B) = {d}
  • c. FIRST(B) = {b, ε} · FOLLOW(B) = {d, $}
  • d. FIRST(B) = {b, ε} · FOLLOW(B) = {d, ε}
  • e. FIRST(B) = {b, d} · FOLLOW(B) = {$}
Como acertar: B → ε obriga ε no FIRST (a "a" e a "e" saem). O FOLLOW nunca tem ε (a "d" sai). Depois de B vem D, e D não pode sumir, então não se copia o FOLLOW(S): a "c" sai.
S1.3 escolha uma opção pegadinha: o parêntese fecha no FOLLOW
Dada a gramática E → T G · G → - T G | ε · T → ( E ) | num, assinale a opção correta:
  • a. FIRST(G) = {-} · FOLLOW(T) = {-, $, )}
  • b. FOLLOW(T) = {-} · FOLLOW(G) = {$, )}
  • c. FOLLOW(E) = {$} · FOLLOW(G) = {$}
  • d. FIRST(T) = {(, num} · FOLLOW(E) = {$, )} · FOLLOW(T) = {-, $, )}
  • e. FIRST(E) = {E, num} · FOLLOW(G) = {-, $, )}
Como acertar: o FOLLOW(E) tem ")" porque E aparece em ( E ). Como G pode sumir, o FOLLOW(T) = FIRST(G) sem ε + FOLLOW(E). A "e" põe uma maiúscula no FIRST, o que nunca acontece.
S1.4 determine
Determine FIRST e FOLLOW: S → A b | c · A → a A | ε
Resposta: FIRST(S) = {a, b, c} (o A some, então entra o b) · FIRST(A) = {a, ε}
FOLLOW(S) = {$} · FOLLOW(A) = {b}
S1.5 determine (a mesma estrutura do slide, com operadores trocados)
Determine FIRST e FOLLOW: X → Y W · W → or Y W | ε · Y → Z K · K → and Z K | ε · Z → not Z | true
Resposta: FIRST(X) = FIRST(Y) = FIRST(Z) = {not, true} · FIRST(W) = {or, ε} · FIRST(K) = {and, ε}
FOLLOW(X) = {$} · FOLLOW(W) = {$} · FOLLOW(Y) = {or, $} · FOLLOW(K) = {or, $} · FOLLOW(Z) = {and, or, $}

5. Itens, CLOSURE, GOTO, coleção — colinha §1 e §6

S5.1 assinale as corretas pegadinha: faltou uma regra no CLOSURE
Dadas as produções S' → S · S → x S y | z, assinale as corretas:
  • a. O primeiro item canônico é GOTO({S' → .S}, S)
  • b. CLOSURE(S' → .S) = {S' → .S, S → .xSy, S → .z}
  • c. CLOSURE(S' → .S) = {S' → .S, S → .xSy}
  • d. GOTO(I0, x) = {S → x.Sy, S → .xSy, S → .z}
  • e. GOTO(I0, S) = {S' → S.}
Como acertar: I0 é sempre CLOSURE (a "a" sai). Se o ponto vem antes do S, todas as regras de S entram (a "c" esqueceu S → .z). Na "d", o ponto passou do x e ficou antes do S, então o CLOSURE traz as duas regras de S.
