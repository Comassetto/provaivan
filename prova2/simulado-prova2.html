1. FIRST e FOLLOW — colinha §3

S1.1 pegadinha: $ a mais no FOLLOW e FIRST incompleto

Dada a Gramática a seguir, assinale a opção que apresenta corretamente os conjuntos FIRST e FOLLOW:

G = (N, T, P, D)
N = {D, E, F}
T = {p, q, r, (, )}
P = {
    D -> p ( E ) F
    E -> q | q E
    F -> r | p | p F
}

Escolha uma opção:

  • a. FIRST(D) = {p, (} · FIRST(E) = {q} · FIRST(F) = {r, p}
      FOLLOW(D) = {$} · FOLLOW(E) = {)} · FOLLOW(F) = {$}
  • b. FIRST(D) = {p} · FIRST(E) = {q} · FIRST(F) = {r, p}
      FOLLOW(D) = {$} · FOLLOW(E) = {), $} · FOLLOW(F) = {$}
  • c. FIRST(D) = {p} · FIRST(E) = {q} · FIRST(F) = {r, p}
      FOLLOW(D) = {$} · FOLLOW(E) = {)} · FOLLOW(F) = {$}
  • d. FIRST(D) = {p} · FIRST(E) = {q} · FIRST(F) = {r}
      FOLLOW(D) = {$} · FOLLOW(E) = {)} · FOLLOW(F) = {$}
  • e. FIRST(D) = {$} · FIRST(E) = {)} · FIRST(F) = {$}
      FOLLOW(D) = {p} · FOLLOW(E) = {q} · FOLLOW(F) = {r, p}
Como acertar: a "e" tem $ no FIRST: sai. D só começa com p, então a "a" sai. F tem regras que começam com r e com p, então a "d" sai. E só aparece antes do ")", então FOLLOW(E) = {)} e a "b" sai.
S1.2 pegadinha: ε no FOLLOW e $ a mais

Dada a Gramática a seguir, assinale a opção que apresenta corretamente os conjuntos FIRST e FOLLOW:

G = (N, T, P, S)
N = {S, B, D}
T = {a, b, d}
P = {
    S -> a B D
    B -> b | ε
    D -> d
}

Escolha uma opção:

  • a. FIRST(S) = {a} · FIRST(B) = {b} · FIRST(D) = {d}
      FOLLOW(S) = {$} · FOLLOW(B) = {d} · FOLLOW(D) = {$}
  • b. FIRST(S) = {a} · FIRST(B) = {b, ε} · FIRST(D) = {d}
      FOLLOW(S) = {$} · FOLLOW(B) = {d} · FOLLOW(D) = {$}
  • c. FIRST(S) = {a} · FIRST(B) = {b, ε} · FIRST(D) = {d}
      FOLLOW(S) = {$} · FOLLOW(B) = {d, $} · FOLLOW(D) = {$}
  • d. FIRST(S) = {a} · FIRST(B) = {b, ε} · FIRST(D) = {d}
      FOLLOW(S) = {$} · FOLLOW(B) = {d, ε} · FOLLOW(D) = {$}
  • e. FIRST(S) = {a, b} · FIRST(B) = {b, ε} · FIRST(D) = {d}
      FOLLOW(S) = {$} · FOLLOW(B) = {d} · FOLLOW(D) = {d}
Como acertar: B -> ε obriga ε no FIRST(B): a "a" sai. FOLLOW nunca tem ε: a "d" sai. S só começa com a: a "e" sai. Depois de B vem D, que não some, então não se copia o FOLLOW(S): a "c" sai.
S1.3 pegadinha: o parêntese que entra no FOLLOW

Dada a Gramática a seguir, assinale a opção que apresenta corretamente os conjuntos FIRST e FOLLOW:

G = (N, T, P, E)
N = {E, G, T}
T = {-, (, ), num}
P = {
    E -> T G
    G -> - T G | ε
    T -> ( E ) | num
}

Escolha uma opção:

  • a. FIRST(E) = {(, num} · FIRST(G) = {-} · FIRST(T) = {(, num}
      FOLLOW(E) = {$, )} · FOLLOW(G) = {$, )} · FOLLOW(T) = {-, $, )}
  • b. FIRST(E) = {(, num} · FIRST(G) = {-, ε} · FIRST(T) = {(, num}
      FOLLOW(E) = {$, )} · FOLLOW(G) = {$, )} · FOLLOW(T) = {-}
  • c. FIRST(E) = {(, num} · FIRST(G) = {-, ε} · FIRST(T) = {(, num}
      FOLLOW(E) = {$} · FOLLOW(G) = {$} · FOLLOW(T) = {-, $}
  • d. FIRST(E) = {(, num} · FIRST(G) = {-, ε} · FIRST(T) = {(, num}
      FOLLOW(E) = {$, )} · FOLLOW(G) = {$, )} · FOLLOW(T) = {-, $, )}
  • e. FIRST(E) = {(, num} · FIRST(G) = {-, ε} · FIRST(T) = {(, num}
      FOLLOW(E) = {$, )} · FOLLOW(G) = {-, $, )} · FOLLOW(T) = {-, $, )}
Como acertar: G -> ε obriga ε no FIRST(G): a "a" sai. E aparece em ( E ), então o ")" entra no FOLLOW(E): a "c" sai. G é sempre o último, então FOLLOW(G) = FOLLOW(E), sem "-": a "e" sai. Como G some, T também copia o FOLLOW(E): a "b" sai.
S1.4 determine

Determine os conjuntos FIRST e FOLLOW da gramática a seguir:

G4: { S -> A b | c
        A -> a A | ε}
Resposta: FIRST(S) = {a, b, c} (o A some, então entra o b) · FIRST(A) = {a, ε}
FOLLOW(S) = {$} · FOLLOW(A) = {b}
S1.5 determine (a mesma estrutura do slide, com operadores trocados)

FOLLOW(X) = {$} · FOLLOW(W) = {$} · FOLLOW(Y) = {or, $} · FOLLOW(K) = {or, $} · FOLLOW(Z) = {and, or, $}

  • b. CLOSURE(S' -> .S) = {S' -> .S, S -> .xSy, S -> .z}
  • c. CLOSURE(S' -> .S) = {S' -> .S, S -> .xSy}
