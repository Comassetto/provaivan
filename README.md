# Linguagens Formais e Compiladores — estudo para as Provas 1 e 2

Pasta de estudo compartilhada. Slides das Aulas 1–6, gabaritos das listas, e materiais prontos gerados com o Claude Code (guia de estudo, resumos e exercícios resolvidos).

**Prova 1:** `Guia de Estudo - LFC Prova 1 (impressão, 6 pags).pdf`, depois os exercícios de `Material Prova 1 - LFC (compacto, 6 pags).pdf`.

**Prova 2:** `Colinha Prova 2 - LFC (3 pags).pdf` (receitas passo a passo para cada tipo de questão) + `Questões Prova 2 - LFC (respostas marcadas, 8 pags).pdf` (exercícios das listas, dos slides e do AVA com a resposta marcada). Slides em `prova2/conteudos/`.

**Usando com o Claude Code:** clone o repositório, abra o Claude Code dentro da pasta e pergunte. O arquivo `CLAUDE.md` já dá ao Claude o contexto da disciplina, o escopo da prova, onde está cada material e como explicar (do zero, passo a passo).

```
git clone https://github.com/Comassetto/provaivan.git
cd provaivan
claude
```
